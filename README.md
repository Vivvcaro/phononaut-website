# Phononaut website

The Phononaut website: a home page and a privacy policy page. Plain HTML and CSS with a little JavaScript, no build step. Built from the Figma frame "Option no video" on the page "Final Websites" in "Phantom Fish – Phononaut – Websites", and the frame "Phononaut · Privacy policy page (DRAFT)" beside it.

## See it on your computer

Open `index.html` in a browser.
