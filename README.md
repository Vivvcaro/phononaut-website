# Phononaut website

The Phononaut website: a home page, a science page and a privacy policy page. Plain HTML and CSS with a little JavaScript, no build step. Built from the Figma frame "Option no video" on the page "Final Websites" in "Phantom Fish – Phononaut – Websites", and the frames "Phononaut · Science page" and "Phononaut · Privacy policy page (DRAFT)" beside it.
